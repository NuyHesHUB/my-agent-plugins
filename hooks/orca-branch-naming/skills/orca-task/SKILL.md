# Orca Task

사용자가 준 작업 프롬프트를 인자로 플러그인 스크립트를 실행한다.

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/orca-task" "<사용자의 작업 프롬프트>"
```

- 사용자가 repo를 지정하면 `--repo name:<repo>` 를 붙인다. 지정하지 않으면 현재 Orca
  컨텍스트의 repo로 생성된다 (Orca 터미널 밖이면 repo 지정이 필요하다).
- 다른 에이전트를 원하면 `--agent codex` 등을 붙인다. 기본은 claude.
- 스크립트가 출력한 생성 결과(이름, 경로)와 롤백 명령을 사용자에게 그대로 전달한다.
- 이름 형식이 맞지 않아 실패하면 한 번 재실행해보고, 그래도 실패하면 오류를 보고한다.
- 생성된 워크스페이스의 브랜치에는 `/` 가 포함되므로 orca-branch-naming 훅은 개입하지 않는다.
